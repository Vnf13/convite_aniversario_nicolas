🎉 Convite de Aniversário – 1 Ano do Nicolas

Este repositório contém um projeto especial desenvolvido para criar o convite digital de 1 ano do meu filho, Nicolas.
O objetivo foi produzir um convite simples, bonito e funcional, que pudesse ser compartilhado facilmente com amigos e familiares.

💡 Sobre o Projeto

Criado como um convite digital personalizado

Desenvolvido com carinho para comemorar o primeiro aniversário

Pode servir de inspiração ou referência para outros modelos de convites

🧰 Tecnologias utilizadas

(caso deseje, posso complementar com base no que você usou)

HTML

CSS

JavaScript

Imagens e elementos personalizados do tema da festa

🎈 Objetivo

O propósito deste repositório é guardar o projeto como lembrança e referência, além de facilitar o compartilhamento do código.
